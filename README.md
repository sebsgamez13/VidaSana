# VidaSana

Web básica en React + Vite (sin backend).

## Ejecutar

```bash
npm install
npm run dev
```

Abre http://localhost:5173

## Estructura

- `src/App.jsx` – estado global (vista activa, hábitos y retos)
- `src/components/Navbar.jsx` – navegación Inicio / Mis retos
- `src/components/Progress.jsx` – anillo de progreso, barra, check y placeholder de imagen
- `src/components/Icons.jsx` – iconos SVG (manzana, corredor, cerebro, gota, zapato, loto, hojas)
- `src/pages/Inicio.jsx` y `src/pages/MisRetos.jsx` – vistas
- `src/index.css` – estilos (colores en `:root`)
